# Assets de marca

Colocar aquí el logotipo oficial de BX+ (`logo-bx.svg` o `.png`) tomado del manual de identidad.
Hoy la app usa un wordmark tipográfico provisional (`.logo` en index.html); para usar el logo oficial,
sustituir ese span por `<img src="assets/logo-bx.svg" alt="BX+" height="26">` — y en despliegue
single-file, incrustarlo como data URI. Los colores en `:root` de index.html son aproximados:
ajustar con los valores oficiales del manual.
